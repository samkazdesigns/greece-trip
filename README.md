# Greece · Nov 11–16, 2026

A mobile-first itinerary for six days in Greece: Athens → Delphi → Meteora → Thermopylae → Athens.

- The main screen is a timeline map of the day. Tap a stop to highlight it; **Open in Maps** jumps to Google Maps.
- The bottom tab expands into the day's full schedule. Stops on the map and rows in the list highlight together.
- The arrows on the tab (or a sideways swipe, or the dots up top) change the day.

Plain HTML, CSS and JavaScript — no build step. The whole itinerary lives in `data.js`.

To preview locally, serve the folder (for example `python -m http.server`) and open it in a browser.
